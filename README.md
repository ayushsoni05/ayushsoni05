### **Creative Vision & Motion Philosophy**

I build **hyper-visual, 3D interactive web experiences and kinetic design systems** that bridge the boundary between **cinema-grade motion graphics and full-stack software architecture**.

- **3D & Experiential Tech**: Three.js, React Three Fiber, WebGL shaders, Spline 3D scene compositing, procedural meshes, PBR ray-traced lighting models.
- **Motion Graphics & Fluid Interactions**: Framer Motion spring physics, Webflow Interactions 2.0, GSAP ScrollTrigger timeline choreography, Lottie SVG animations.
- **Full-Stack & Fintech Systems**: React.js, Next.js, Node.js, Express.js, MongoDB, RESTful APIs, live bullion rate WebSockets, Razorpay payment engines.
- **AI Vision Pipelines**: HTML5 Canvas Computer Vision, visual feature classification, and automatic 3D CAD/parametric replication.
